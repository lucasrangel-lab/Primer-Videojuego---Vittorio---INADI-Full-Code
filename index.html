Tu primer juego
en GameMaker.

Una guía paso a paso para aprender a utilizar GameMaker creando tu propio personaje, moviéndolo y agregando tu primer enemigo.

🎯 Misión: terminar una pequeña escena jugable.
Misiones
🚀
MISIÓN 01

Crear nuestro proyecto

Antes de comenzar necesitamos crear el proyecto donde estará nuestro juego.

1

Abre GameMaker.

2

En la pantalla inicial selecciona New → GameMaker Language.

3

Si aparece la selección de plantilla, elige Blank Game.

4

Ponle como nombre: MiPrimerJuego

💡 IMPORTANTE

Guarda el proyecto en una carpeta que puedas encontrar fácilmente.

🖼️
MISIÓN 02

Crear nuestro primer Sprite

Un Sprite es una imagen que podemos utilizar dentro del juego.

🧍
Personaje
👾
Enemigo
🪙
Moneda

Crear el Sprite

1

Busca el panel Asset Browser.

2

Busca la carpeta Sprites.

3

Haz clic derecho sobre Sprites.

4

Selecciona Create → Sprite.

5

Llámalo: spr_player

🧠 ¿QUÉ SIGNIFICA spr_player?

spr nos indica que es un Sprite. player significa jugador.

🎨 Ahora dibuja tu personaje

Abre el Sprite haciendo doble clic sobre él. Utiliza el editor de imágenes de GameMaker para crear tu personaje.

No necesitas hacer un dibujo perfecto. Puede ser un cuadrado, un robot, un personaje, una nave o lo que quieras.

📦
MISIÓN 03

Crear nuestro primer Objeto

Ahora tenemos la imagen del personaje. Pero necesitamos algo que pueda hacer cosas.

🖼️ Sprite ¿Cómo se ve?
→
📦 Objeto ¿Qué hace?
🧠 CONCEPTO CLAVE

El Sprite es la apariencia. El Objeto representa algo que existe dentro del juego y puede tener comportamiento.

Crear el objeto

1

En Asset Browser, busca Objects.

2

Haz clic derecho → Create → Object.

3

Ponle el nombre: obj_player

4

Busca la propiedad Sprite.

5

Selecciona spr_player.

💡 RECUERDA

Ahora tenemos:

spr_player Imagen
→
obj_player Personaje dentro del juego

MISIÓN 06

Hacer que el personaje camine

¡Ahora sí! Vamos a programar nuestro personaje.

💻 VAMOS A USAR GML

GML es el lenguaje de programación de GameMaker. Lo utilizaremos para decirle al personaje qué debe hacer.

➡️ Mover hacia la derecha

1

Abre obj_player.

2

Pulsa Add Event.

3

Selecciona: Key Down → Right.

4

Escribe: 

x += 4;
🧠 ¿QUÉ SIGNIFICA?

x representa la posición horizontal del objeto.

x += 4 significa: mover el objeto 4 píxeles hacia la derecha.

⬅️ Mover hacia la izquierda

Crea otro evento: Key Down → Left. 

x -= 4;

⬆️ Mover hacia arriba

Crea: Key Down → Up. 

y -= 4;

⬇️ Mover hacia abajo

Crea: Key Down → Down. 

y += 4;
⬆️
y - 4
⬅️ 🧍 ➡️ x - 4 / x + 4
⬇️
y + 4
🧠 RECUERDA

X controla izquierda y derecha.

Y controla arriba y abajo.

MISIÓN 07

Crear nuestro primer enemigo

Nuestro personaje ya puede moverse. Ahora vamos a crear algo que pueda encontrar dentro del juego.

🎨 Crear el Sprite del enemigo

1

Ve a Sprites → Create → Sprite.

2

Llámalo: spr_enemy.

3

Dibuja tu propio enemigo.

🎨 TU DISEÑO

Puede ser un alien, robot, fantasma, monstruo, nave o cualquier cosa que quieras.

📦 Crear el Objeto enemigo

1

Ve a Objects → Create → Object.

2

Llámalo: obj_enemy.

3

Asígnale el Sprite: spr_enemy.

spr_enemy Imagen del enemigo
→
obj_enemy Enemigo dentro del juego

📍 Colocarlo en la Room

Abre nuevamente rm_game y arrastra obj_enemy dentro del escenario.

MISIÓN FINAL

Personaliza tu juego

Ya conoces las herramientas básicas. Ahora toca experimentar.

🎨 1. Personaliza tu personaje

Cambia el diseño de spr_player.

👾 2. Personaliza tu enemigo

Cambia el diseño de spr_enemy.

⚡ 3. Cambia la velocidad

Busca uno de tus códigos de movimiento. 

x += 4;

Cambia el 4 por: 

x += 2;

Después prueba: 

x += 8;

¿Qué diferencia notas?

👾 4. Agrega otro enemigo

Coloca una segunda instancia de obj_enemy en la Room.
